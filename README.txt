Cara pakai:
1. Buka index.html atau upload isi folder ini ke GitHub Pages.
2. Nama tamu dibaca dari URL ?to=Nama%20Tamu.
3. Musik saat ini memakai music/wedding.mp3. Ganti file itu jika ingin mengganti lagu pertama.
4. Foto Gallery dapat dimasukkan ke folder gallery/ pada tahap berikutnya.
