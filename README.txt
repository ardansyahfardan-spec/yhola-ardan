YHOLA & ARDAN — INTERACTIVE INVITATION V11

Master canvas: 1080x1920 (9:16). The entire stage scales as one unit on phone/tablet/desktop.

Flow:
Loading full bushes -> bushes open left/right -> Start screen -> START -> tutorial -> Lanjut Menjelajah -> main scene.

Main scene uses the latest BG UTAMA KSONGAN.png supplied by the user.

Interactive objects:
- YHOLA & ARDAN sign: personal invitation popup
- Two-person character: voice-note popup
- Cerita Kami, Date & Venue, Gallery, Gift, RSVP: dedicated popups with mini/object art
- Lamp: ON/OFF with glow behind lamp and hand tutorial
- Chair: occasional jolt + procedural creak SFX

Music: music1 -> music2 -> music1 loop. MUSIC/MUTE asset switches with state.

SFX are generated locally with Web Audio so the prototype does not require separate SFX files.

Replaceable files are kept in assets/, audio/, and gallery/.
